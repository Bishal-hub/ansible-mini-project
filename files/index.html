📘 Ansible Tutorial

Learn Ansible step-by-step with commands and real outputs.

1️⃣ What is Ansible?

Ansible is an open-source automation tool used for configuration management, application deployment, and orchestration.

2️⃣ Ansible Architecture

  • Control Node (Master)
  • Managed Nodes (Workers)
  • SSH-based communication

3️⃣ Install Ansible (Ubuntu)

sudo apt update
sudo apt install -y ansible

4️⃣ Inventory File

[workers]
worker1 ansible_host=10.0.0.11
worker2 ansible_host=10.0.0.12
worker3 ansible_host=10.0.0.13

5️⃣ Test Connectivity

ansible all -m ping

Output:

worker1 | SUCCESS => pong
worker2 | SUCCESS => pong
worker3 | SUCCESS => pong

6️⃣ Ansible Playbook Example

- name: Install nginx
apt:
  name: nginx
  state: present

7️⃣ Run Playbook

ansible-playbook deploy-website.yml

Output:

changed=2 ok=3 failed=0

8️⃣ Verify Website

Open browser:

http://<worker-ip>

🎉 Conclusion

This website was deployed using Ansible automation. You learned inventory, playbooks, modules, and real execution outputs.
